# Common Device Tree for Xiaomi Snapdragon 8 Gen 1 / 8+ Gen 1 (sm8450-common)

This repository provides common device configurations, HAL wrappers, and SELinux policies for Xiaomi Snapdragon 8 Gen 1 (sm8450) and Snapdragon 8+ Gen 1 (sm8475) platforms (including Xiaomi 12, Xiaomi 12 Pro, Xiaomi 12S, Xiaomi 12S Pro, and POCO F4 GT).
